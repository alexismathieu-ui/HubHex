IMPORT POSTMAN DANS VS CODE / CURSOR
====================================

Si l'import echoue, essaie dans cet ordre :

1) UN SEUL FICHIER A LA FOIS
   - D'abord : HubHex.postman_collection.json
   - Ensuite : HubHex-local.postman_environment.json
   (ne pas importer les 2 en meme temps)

2) CHEMIN LOCAL WINDOWS
   - Postman VS Code : bouton Import
   - Choisir "File" (pas Folder)
   - Naviguer vers : C:\Users\User\HubHex\postman\
   - Selectionner le fichier .json

3) ENVIRONNEMENT
   - En haut a droite de Postman : selectionner "HubHex local"
   - Variables : email, password, baseUrl (http://localhost:4000)

4) TEST
   - Lancer : cd backend && npm run dev
   - Requete "01 Auth" > "Login"
   - Puis "02 Profil" > "GET me"

ALTERNATIVE (souvent plus simple dans Cursor)
   - Extension "REST Client" (humao.rest-client)
   - Ouvrir le fichier : http/hubhex.http
   - Cliquer "Send Request" au-dessus de chaque bloc
