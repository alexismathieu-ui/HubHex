================================================================================
1. VISION ET ARCHITECTURE
================================================================================

HubHex = plateforme de gestion de projets dev (soutenance), type mini-GitHub interne :
chaque depot est heberge sur HubHex (pas un lien GitHub externe), chemin public type :
  username/slug-du-depot

Stack :
  - Frontend : Next.js 16 (App Router), React 19, TypeScript strict, Tailwind 4, Monaco
  - Backend  : Express 5, Node.js (JavaScript) — port 4000
  - BDD      : PostgreSQL (schema au boot via ensureDatabaseSchema())
  - Auth     : JWT HS256 (localStorage hubhex_token), invalidation si changement MDP

Monorepo :
  HubHex/
    backend/          API Express (JS) + scripts (export schema, tests, reset-password)
    frontend/         Application Next.js (100 % .ts / .tsx, tsconfig strict)
    database/         hubhex_schema.sql (export structure)
    docs/             Doc utilisateur, technique, soutenance, checklist demarrage
    postman/          Collection tests API
    http/             Fichiers REST Client
    README.md
    HubHex_plan_complet.txt
    HubHex_etat_projet.txt (ce fichier)

Depot GitHub : https://github.com/alexismathieu-ui/HubHex

Demarrage local (detail) : docs/CHECKLIST_DEMARRAGE_LOCAL.md
  Terminal 1 : cd backend && npm run dev   → http://localhost:4000
  Terminal 2 : cd frontend && npm run dev  → http://localhost:3000
