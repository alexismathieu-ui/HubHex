================================================================================
1. VISION ET ARCHITECTURE
================================================================================

HubHex = plateforme de gestion de projets dev (soutenance), type mini-GitHub interne :
chaque depot est heberge sur HubHex (pas un lien GitHub externe), chemin public type :
  username/slug-du-depot

Stack :
  - Frontend : Next.js 16 (App Router), React, Tailwind CSS — http://localhost:3000
  - Backend  : Express 5, Node.js — http://localhost:4000
  - BDD      : PostgreSQL (schema cree au demarrage via ensureDatabaseSchema())
  - Auth     : JWT HS256 dans localStorage (cle hubhex_token), invalidation si changement MDP

Monorepo :
  HubHex/
    backend/          API + scripts utilitaires
    frontend/         Application Next.js
    postman/          Collection + environnement pour tests API
    http/             Fichier .http (alternative REST Client dans VS Code)
    HubHex_plan_complet.txt   Plan CDC + differentiation (checklist)
    README.md         Quasi vide (2 lignes seulement — A FAIRE)

Demarrage :
  Terminal 1 : cd backend && cp .env.example .env && npm install && npm run dev
  Terminal 2 : cd frontend && npm install && npm run dev
  .env backend : DATABASE_URL, JWT_SECRET (32+ car.), FRONTEND_URL, ALLOW_DEV_RESET_TOKEN
