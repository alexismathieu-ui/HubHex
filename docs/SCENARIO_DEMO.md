# Scenario de demonstration (5–10 min)

## Accroche (30 s)

> HubHex n'est pas seulement un gestionnaire de taches : c'est un hub ou chaque depot est heberge sur la plateforme, avec une stack documentee, un journal de decisions et un graphe qui relie vos projets dans le temps.

## Parcours

1. **Connexion** — `demo@hubhex.dev` / `DemoHubHex1!`
2. **Tableau de bord** — activite et compteurs
3. **Nouveau depot depuis template** — « API REST securisee » ou depot existant `demo/portfolio-demo`
4. **Fichiers** — importer un fichier ou editer un fichier texte
5. **Kanban** — glisser une tache vers « Termine »
6. **Stack** — montrer PostgreSQL + snippet
7. **Journal** — lire l'entree « Choix monorepo »
8. **Graphe** — lier deux depots (relation « meme techno »)
9. **Communaute** — projet public, commentaire
10. **Profil** — pseudo / avatar
